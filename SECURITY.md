Security Policy

Supported Versions

Security fixes are applied to the latest version of the project.

Version| Supported
1.x| Yes

Reporting a Vulnerability

If you discover a security vulnerability, please do not publicly disclose the issue before it can be investigated.

Open a private security report through GitHub's security reporting features when available.

When reporting an issue, include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any relevant logs or evidence that do not contain sensitive information

Please do not include passwords, API keys, tokens, or other private credentials in a report.

Responsible Disclosure

We appreciate responsible disclosure and will investigate legitimate security reports as quickly as possible.
